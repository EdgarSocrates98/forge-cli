# Threat Model — §8.1/§8.2 (spec 008)

Escopo: Forge CLI 2.0 + Forge Portal 2.0 + adapter contract `forge/PortalApi/1`.
Ativos: workspace do usuário, `.env`/segredos, configs de hosts de IA,
integridade de instalação, receipts/audit trail.

## §8.1 Ameaças

| #   | Ameaça                                 | Asset                  | Caminho do atacante                       | Mitigação implementada                                                                                                                                    | Status                                                                  |
| --- | -------------------------------------- | ---------------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 1   | Repositório remoto malicioso           | workspace              | URL hostil em `forge-cli.repos.json`/args | `isSafeRepoUrl` allowlist + `--trust-custom` exigido p/ scripts custom; scripts nunca rodam sem confiança explícita                                       | MITIGATED                                                               |
| 2   | Manifest `forge.json` manipulado       | planner/integração     | campos hostis (paths, args)               | `readForgeManifest` strict: só campos conhecidos, tokens `SAFE_TOKEN`, sem paths/espaços/opções; schema declarado inválido → descarte total (fail-closed) | MITIGATED                                                               |
| 3   | Script de instalação não confiável     | máquina do usuário     | setup.ps1 malicioso em repo não-confiável | execução só p/ repos builtin trusted ou `--trust-custom`; plano exibe o script antes                                                                      | MITIGATED                                                               |
| 4   | Symlink/junction + path traversal      | FS fora do workspace   | link em repo dir, entrada de manifest     | `isLinkOrJunction` recusa; `resolveInside`/`isSafeRepoName`/`isSafeEntryPath` (bundle) bloqueiam `..`                                                     | MITIGATED (tests: portal traversal + symlink escape suites)             |
| 5   | Config MCP maliciosa                   | hosts de IA            | merge-json com chaves/argv hostis         | merge restrito a chaves declaradas (`mcpServers[forgeId]`); comando copiável em vez de execução opaca; backup antes de escrever                           | MITIGATED                                                               |
| 6   | Prompt injection via tool descriptions | modo IA                | descrições forjadas induzem comando       | AI mode: propostas são display-only, schema-validadas, refs re-validados; **zero execução** de conteúdo do modelo                                         | MITIGATED                                                               |
| 7   | Exfiltração de segredos                | .env / config          | env var vazando p/ contexto/log/bundle    | denylist de chave + `redactSecrets` + `SECRET_VALUE_RE` (contexto); `.env` nunca entra em digest/bundle de valores; logs sanitizados                      | MITIGATED (tests: keyless-gate, ai-sanitize, bundle refusal)            |
| 8   | Envenenamento de config de host        | ~/.claude.json etc     | merge errado corrompe host                | plano → confirmação → backup → merge → validação → rollback (`hosts rollback`)                                                                            | MITIGATED                                                               |
| 9   | Race condition / TOCTOU plan→apply     | planos                 | plano adulterado entre plan/apply         | plan token hash+expiry (`planner.verifyPlan`), receipts imutáveis                                                                                         | MITIGATED                                                               |
| 10  | Conflito de porta                      | Portal                 | porta ocupada                             | bind em `127.0.0.1`, porta explícita/0 (efêmera); erro tipado                                                                                             | MITIGATED                                                               |
| 11  | SSRF em connectivity checkers          | Portal/CLI             | URL de host redireciona p/ rede interna   | checkers só leem config/estado local; sem fetch para host declarado (test: `test_host_field_never_fetches`)                                               | MITIGATED                                                               |
| 12  | CSRF / browser→localhost               | Portal                 | página externa POSTa no server local      | session header exigido p/ mutação; Origin não-loopback rejeitado; form-posts rejeitados; DNS-rebinding guard (Host header)                                | MITIGATED (24-test suite `test_security_c5.py`)                         |
| 13  | Supply chain                           | dependências           | dep nova comprometida                     | conjunto de runtime aprovado travado; `npm ci` audit 0 vulns; sem deps novas desde F0                                                                     | MITIGATED (vigilância contínua — não há gate de age pinning ainda → P3) |
| 14  | Exfiltração de dados por IA            | modo IA                | contexto com dados sensíveis              | contexto limitado 8 KiB, seções droppáveis, secrets 3-layer hygiene, bridge local BYOK, sem telemetria                                                    | MITIGATED                                                               |
| 15  | Desserialização                        | planos/receipts/bundle | JSON hostil lido                          | parse defensivo + schema check; manifest de integridade sha256 rejeita bytes adulterados; `verifyIntegrityManifest` recusa path traversal antes do read   | MITIGATED                                                               |
| 16  | Log injection                          | artefatos              | CRLF em paths/mensagens                   | redactSecrets + linha única sanitizada; test `test_crlf_cannot_forge_log_lines`                                                                           | MITIGATED                                                               |
| 17  | Integridade de release                 | dist/pack              | bundle adulterado                         | `npm pack` tarball + integrity manifest de bundle; checksums sha256 por arquivo                                                                           | PARTIAL (release signing fora de escopo — pendência P2)                 |
| 18  | Rate limiting / exaustão               | Portal                 | flood de mutações                         | rate limiter em endpoints mutantes (429 within bound — testado); payload cap; bounded concurrency                                                         | MITIGATED                                                               |
| 19  | Sessão sem expiração temporal          | Portal                 | token roubado vale para sempre            | **finding honesto**: sessão é binding-only, sem TTL — `test_session_has_no_time_expiry` documenta                                                         | OPEN — pendência P2 (decisão de produto)                                |

## §8.2 Classes de política → operações

| Classe                    | Operações                                                                                                                                                                              | Permissão exigida                                                           |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| READ_ONLY                 | `status`, `list`, `versions`, `discover`, `recommend`, `ask`, `predict`, `context`, `env inspect`, `doctor`, `hosts list`, `learning status/report`, `bundle verify`, `profile` export | nenhuma (default)                                                           |
| LOCAL_WRITE               | `lock`, `heal` SAFE_AUTOMATIC, `learning enable/disable`, `bundle export`, `hosts plan` (preview)                                                                                      | comando explícito; `.forge-cli/` apenas                                     |
| EXECUTE_TRUSTED_INSTALLER | `install`, `update`, `reinstall`, `clone` c/ scripts                                                                                                                                   | repo builtin trusted OU `--trust-custom`; confirmação interativa / `--yes`  |
| NETWORK_ACCESS            | `install`/`update` (git), `self update`                                                                                                                                                | rede só via git/npm do usuário; `--offline` = zero rede                     |
| HOST_CONFIGURATION        | `hosts register`, `hosts rollback`, `hosts validate`                                                                                                                                   | plano + confirmação + backup + receipt                                      |
| SECRET_UPDATE             | `env plan/init/migrate`, `heal` REVIEW_REQUIRED (ex.: `.env` append)                                                                                                                   | revisão explícita por chave; `--yes` sozinho não basta (provado no Gate C5) |
| DESTRUCTIVE_CHANGE        | `uninstall`, `reinstall --clean`, `hosts rollback`                                                                                                                                     | `--yes`/confirmação + backup + receipt; nunca silencioso                    |

## Veredito §8.3

Nenhuma falha crítica aberta sem mitigação. Pendências: #17 (assinatura de
release) e #19 (TTL de sessão) — ambas documentadas como P2, não bloqueantes
para homologação **PASS_WITH_LIMITATIONS**.
