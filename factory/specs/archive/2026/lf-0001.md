# Context

`forge-cli` is a new, modern interactive CLI (Node.js >= 20, ESM + TypeScript) that manages, clones, and auto-configures a fixed set of 8 repositories in the "Forge" ecosystem owned by EdgarSocrates98. This spec scaffolds the entire project from an empty repo. Source prompt: `prompt_evo_inicial.md` at repo root.

Stack required by the prompt:

- TypeScript compiled with `tsup` (or run directly via `tsx`)
- Interactive UI: `@clack/prompts` + `picocolors`
- ASCII banner: `cfonts` or `figlet`
- Subprocesses: `execa` (^9)

All user-facing strings (prompts, spinners, warnings, summary, outro) in Portuguese (PT-BR).

## CLI flow

- Banner shown via `@clack/prompts` `intro()` plus ASCII art (cfonts/figlet).
- Text prompt asks for install directory, default `./forge-workspace`; resolved to an absolute path; directory created recursively if missing.
- `multiselect` lists all 8 repos, all selected by default; validation blocks proceeding with zero selections.
- A summary (count + target dir) is shown and must be confirmed before work starts.
- Per selected repo, a `spinner` runs:
  - If `<dir>/<repo>` exists and contains `.git` -> `git pull`.
  - Otherwise -> `git clone <url> <dir>/<repo>`.
  - Then OS-specific setup script: on `win32` look for `install.ps1` and run `powershell.exe -NoProfile -ExecutionPolicy Bypass -File install.ps1`; on other platforms look for `install.sh` and run `chmod +x install.sh && ./install.sh`.
  - Missing script -> yellow warning, flow continues (not an error).
  - Clone/script failure -> detailed execa error captured, that item marked failed, remaining repos continue.
- Final consolidated report marks each repo `[OK]` (cloned + installed), `[AVISO]` (cloned, no install script), or `[ERRO]` (clone/script failure), then `outro()` with a friendly message.
- `SIGINT`/clack cancellation handled via `isCancel()` and exits cleanly.
