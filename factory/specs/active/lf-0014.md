  OS/shell today; PowerShell assumptions; Git Bash handling (or absence);
  existing Windows CI coverage.
- `docs/cycle12/python-discovery-audit.md`: every python discovery path in
  every installer + forge-cli preflight (`command -v`, `Get-Command`, `py`,
  registry, managers); confirmed failure modes when python is off-PATH.
- `docs/cycle12/corporate-compatibility-matrix.md`: which of the 10 target
  scenarios (prompt §OBJETIVO) work today per repo, marked confirmed/broken/
  untested — no "probably works".
- `docs/cycle12/implementation-plan.md`: mapping FASE 1–13 requirements to
  concrete files/owners per repo, sequenced, naming which later specs cover
  which requirement.
- Every claim cites a file path + line or a command output; no invented
  versions or capabilities (forge invariant).
