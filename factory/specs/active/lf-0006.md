# Context

sparse — no overall progress, no recovery path for failures, minimal report data.

# Grill Gate

- Overall progress via clack `progress` component (`style: 'block'`, `max = N repos`);
  per-repo spinner/taskLog stays. If rendering conflicts appear, fallback is an
  `i/N` counter inside the spinner label — pick whichever renders correctly.

  poorly with sequential commands; instead the reporter shows each pipeline phase as
  its own step line. (Decided in grilling: skip group(), keep phase messages.)
- Retry prompt appears only when ≥1 repo ended `error`, in interactive mode only.
- Artifacts: none here.
- Implementer: Devin. UI remains PT-BR.
