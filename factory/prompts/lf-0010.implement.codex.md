        # Context

`doctor` (lf-0007) diagnoses; `checkRepoPrereqs` (lf-0009) enforces declared
requirements. Two gaps: doctor can't heal — users must rerun the whole
install for one broken repo; and the python probe checks only
`python`/`python3`/`py` while `setup.ps1` resolves versioned interpreters
(`py -3.12`), so the check can false-fail a machine that would succeed.

  `python3.14`…`python3.10` (POSIX); pass when ANY interpreter meets the
  floor. pip/venv probes use the satisfying exe.
