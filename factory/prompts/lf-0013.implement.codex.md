        # Context

`npm i -g`/`npm link` already works (npm owns the PATH shim), but requires
npm. A `forge-cli install` subcommand makes the CLI self-installable for
anyone: copy the single-file bundle to a user dir, write shims, register
the dir on the user's PATH — no admin, works from any terminal.

# Grill Gate

- Install target: **copy bundle to `~/.forge-cli/bin`** (`index.js` +
  `forge-cli.cmd` on Windows / `forge-cli` sh shim on POSIX). Survives
  repo deletion/move; upgrade = run `forge-cli install` again.
- **`forge-cli uninstall`** included: removes the dir, the guarded
  profile blocks on POSIX, and the user-PATH entry on Windows.
- Windows PATH write: **PowerShell
  `[Environment]::SetEnvironmentVariable('Path', ..., 'User')`** —
  never `setx` (truncates >1024 chars). Read via
  `GetEnvironmentVariable`, append only if absent (case-insensitive
  compare, trailing-slash tolerant).
- `doctor` gains a **warn-level** check: `forge-cli` resolvable on PATH
  (`where` on Windows / `command -v` via `sh -c` on POSIX); when missing,
  suggest `forge-cli install` or `npm i -g`.
- Implementer: Devin.

# Acceptance Criteria

      PATH entry preserving everything else.
